# Spilldatabase

dette skal bli en nettside som man bruke til å holde styr på spill katalogen sin. man skal kunne:
- lage konto 
- logge inn
- lage samlinger
- legge til spill i sin samling
- merkere spill som "skal spille", "spiller", eller "spilt"
- se samlingene sine
- føre inn relevant informasjon om spill og samlinger
